# Ciência Atmosférica

Uma plataforma web educativa para explorar a meteorologia, entender a mecânica dos eventos severos e aprender a identificar os tipos de nuvens.

🔗 **Acesse o site:** [https://nicolasdesouza01.github.io/cienciaatmosferica/site1/](https://nicolasdesouza01.github.io/cienciaatmosferica/site1/)

---

## 📌 O Projeto

O repositório reúne 3 sites independentes e interconectados:

* **Site 1 — Conheça a Meteorologia:** Conceitos fundamentais, equipamentos de monitoramento e parâmetros físicos.
* **Site 2 — Eventos Severos:** A física por trás de tornados, microbursts, vendavais e ciclones.
* **Site 3 — Tipos de Nuvens:** Identificação direta das formações de nuvens por observação visual e leitura de radar.
